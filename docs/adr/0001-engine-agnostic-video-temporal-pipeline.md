# 所有推理引擎统一使用源视频时序管线

VLM 的稀疏推理曾直接降低 AI 视频输出帧率，导致播放卡顿；因此 YOLO、SAM3、VLM 和深度跟踪统一经过引擎无关的抽帧、结果排序和逐源帧渲染管线。各引擎只调整观测频率、并发能力和传播策略，输出始终保持源视频的帧顺序、PTS、时长和音频同步；离线任务保证结果完整，实时预览保证画面新鲜。

## Considered Options

- 让每个引擎单独实现抽帧和排序：拒绝，容易再次产生不同的时基、乱序和重复修复。
- 仅让 VLM 使用时序管线：拒绝，后续引擎会重复遇到相同的帧率和异步结果问题。

## Consequences

- 引擎适配层必须返回带源帧序号和 PTS 的结果。
- 稀疏观测需要有界的结果传播和过期规则。
- 实时模式可以丢弃过期待处理请求，但离线模式不能丢弃观测结果。
